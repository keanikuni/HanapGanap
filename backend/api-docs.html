HanapGanap API reference

REST API for browsing university events, registering, checking in, and issuing certificates. Requests and responses use JSON, except certificate downloads, which return a PDF.

Getting started

Base URL
http://localhost:8000/api
Authentication

Log in with POST /auth/login to get a token. Send it on every protected request. Tokens expire after 24 hours.

Authorization: Bearer <token>
Roles

Each user has one role: guest, student, organizer or admin. The access badge on each endpoint shows who can call it. Admin accounts are created with the seed script, not through registration.

Errors

Errors return a JSON body with a message field.

{ "message": "This event is full" }
StatusMeaning
400Missing or invalid input
401No token, or the token is invalid or expired
403Your role or ownership does not allow this action
404Record or route not found
409Conflict with current state (duplicate, full, closed, in use)
500Server error
Dates

Send dates as ISO 8601 strings with an offset, for example 2026-12-10T09:00:00+08:00.
